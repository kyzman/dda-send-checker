Установить rust (https://rust-lang.org/tools/install/)
Для сборки проекта под Windows дополнительно придётся установить и добавить их в Path:
1. cmake (https://cmake.org/download/)
2. nasm (https://nasm.us/)

в каталоге проекта выполнить для компиляции обоих вариантов для релиза, после чего можно использовать только бинарники из каталога target/release
```powershell
cargo build --release
```

нужно заполнить корректно .env-example и переименовать в .env

для использования при локально доступной базе (без SSH) лучше брать не базовый вариант, а локальный (он более функциональный, т.к. там велась разработка улучшений):
```powershell
cargo run --release --bin local "имя сформированной в DWH таблицы для рассылки"
```
